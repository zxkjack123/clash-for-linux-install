### C1 ✅ `resources/mixin.yaml` — TAB 缩进导致 YAML 无法解析

- **文件**: `resources/mixin.yaml:12`
- **类别**: YAML 语法错误
- **描述**: `rules:` 下的所有条目使用 TAB (`^I`) 缩进。YAML 规范禁止 TAB 用于缩进，任何解析器（包括 Mihomo/Clash）都会拒绝此文件。`cat -A` 确认：
  ```
  rules:$
  ^I- DOMAIN-SUFFIX,wikipedia.org,PROXY
  ```
- **影响**: 仓库版 mixin 完全无法被解析，runtime config merge 时 Wikipedia 规则被跳过。
- **修复**: 所有前导 TAB 已替换为 2-space 缩进。

### C2 ✅ `vpn-tools/launcher.sh` — `run_script` 将脚本名作为参数传给子脚本

- **文件**: `vpn-tools/launcher.sh:44-49`
- **类别**: 逻辑错误
- **描述**: `run_script()` 函数：
  ```bash
  run_script() {
      local s="$1"
      "./$s" "$@"   # $@ 仍然包含 $1=$s
  }
  ```
  调用 `run_script "quick_vpn_check.sh"` 实际执行 `./quick_vpn_check.sh quick_vpn_check.sh`。所有子脚本收到自己的文件名作为多余的 `$1`。
- **影响**: 解析 `$1` 为模式（如 text/json）的脚本将收到错误参数；CLI shortcut `launcher.sh run script.sh` 同样受影响。
- **修复**: 在 `local s="$1"` 后添加 `shift`，使 `"$@"` 不再包含脚本名。

### C3 `vpn-tools/alert_notification.sh` — Webhook payload JSON 注入

- **文件**: `vpn-tools/alert_notification.sh:155-166`
- **类别**: 安全 / 数据损坏
- **描述**: Webhook body 通过 heredoc 直接拼字符串：
  ```bash
  local payload=$(cat <<EOF
  {
    "message": "$ALERT_MESSAGE",
    ...
  }
  EOF

  ```
  若 `ALERT_MESSAGE` 含双引号 `"`、反斜杠 `\` 或换行，payload JSON 格式损坏。攻击者可控的错误消息可能篡改 webhook 语义。
- **影响**: Webhook 消息发送失败或 payload 被篡改。
- **建议修复**: 使用 `jq -n --arg msg "$ALERT_MESSAGE" ...` 构造 JSON，或调用现有的 `nh_json_escape_str` helper（`lib/net_helpers.sh`）。

### H1 ✅ `script/clashctl.sh` — `&&`/`||` 运算符优先级导致 score 双重扣分

- **文件**: `script/clashctl.sh:993` 和 `script/clashctl.sh:1026`
- **类别**: 逻辑错误（运算符优先级）
- **描述**: 两处相同的模式：
  ```bash
  [ "$fails" -gt 20 ] && score=$((score-20)) || [ "$fails" -gt 5 ] && score=$((score-10))
  ```
  由于 `&&`/`||` 左结合，当 `fails > 20` 时：`-gt 20` 为 true → `score-=20` → 表达式结果为 true → `||` 短路跳过第二个 `[]` → 但 `&&` 仍执行 `score-=10`。总扣分 -30 而非 -20。
- **影响**: 健康评分和 metrics 计算偏低。
- **修复**: 已改为 `if/elif/fi` 结构。
