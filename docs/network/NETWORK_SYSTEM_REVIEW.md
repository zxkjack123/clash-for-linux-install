## 🚀 新增功能详解

### 1. 网络健康监控系统

**文件**: `vpn-tools/network_health_monitor.sh`

**核心功能**:
- ✅ 自动监控 4 大类服务（AI、开发、流媒体、国内网站）
- ✅ 计算综合健康分数（0-100）和等级（A-F）
- ✅ 自动检测问题并触发修复
- ✅ 记录历史数据用于趋势分析
- ✅ 支持一次性检查和守护进程模式

**监控指标**:
```
AI服务:     成功率、平均延迟
开发服务:   成功率、平均延迟
流媒体:     成功率、平均延迟
国内网站:   成功率、平均延迟
```

**自动修复逻辑**:
```
健康分数 < 60        → 运行时修复
AI 成功率 < 50%      → AI 优化
流媒体成功率 < 50%   → 流媒体优化
服务不可用           → 重启服务
```

### 2. 智能规则优化器

**文件**: `vpn-tools/intelligent_rule_optimizer.sh`

**核心功能**:
- ✅ 测试不同节点访问各类网站的性能
- ✅ 为每类网站自动推荐最佳节点
- ✅ 生成优化后的 proxy-groups 和 rules 配置
- ✅ 学习历史数据持续改进
- ✅ 支持自定义网站分类

**支持的网站分类**:
```
- AI（ChatGPT、Claude、Anthropic）
- 开发（GitHub、NPM、PyPI、Crates）
- 流媒体（YouTube、Netflix、Twitch、Spotify）
- 游戏（Steam、Epic）
- 会议（Zoom、Teams）
- 购物、社交、新闻等
```

**优化流程**:
1. 获取可用节点列表
2. 测试每个节点访问不同类别网站的性能
3. 根据延迟和成功率计算得分
4. 为每个类别选择最佳节点
5. 生成优化建议配置

### 3. 多渠道告警通知系统

**文件**: `vpn-tools/alert_notification.sh`

**核心功能**:
- ✅ 支持多种通知方式（桌面、Webhook、邮件）
- ✅ 三级告警（INFO、WARNING、CRITICAL）
- ✅ 智能去重和频率限制
- ✅ 告警历史记录

**通知渠道**:
```
- 桌面通知: notify-send/zenity/kdialog
- 日志文件: 持久化记录
- Webhook:   企业微信、钉钉、自定义
- 邮件:      mail/sendmail
```

**频率控制**:
- 相同告警 5 分钟内只发送一次
- 避免告警风暴
- 保留完整历史记录

### 4. 定时任务调度系统

**文件**: `vpn-tools/setup_monitoring_cron.sh`

**核心功能**:
- ✅ 一键安装所有定时监控任务
- ✅ 自动备份和恢复 crontab
- ✅ 任务状态查看和管理
- ✅ 脚本测试功能

**定时任务清单**:
```
每10分钟:    网络健康检查（自动修复）
每10分钟:    运行时守护检查（自动修复）
每小时:      健康快照记录
每天03:00:   智能规则学习
每周日04:00: 全面规则分析
每天02:00:   日志清理（保留30天）
```

### 5. 可视化监控仪表盘

**文件**: `vpn-tools/network_dashboard.sh`

**核心功能**:
- ✅ 实时显示系统状态
- ✅ 健康分数和等级可视化
- ✅ 服务详情表格展示
- ✅ 最近告警列表
- ✅ 性能趋势 ASCII 图表
- ✅ 快速操作菜单
- ✅ 支持交互式和持续刷新模式

**显示内容**:
```
系统概览:
  - Clash服务状态
  - API状态和版本
  - 当前节点
  - 运行时间

健康状态:
  - 健康分数（0-100）
  - 健康等级（A/B/C/D/F）
  - 进度条可视化
  - 最近检查时间

服务详情:
  - AI、开发、流媒体、国内网站
  - 状态图标、成功率、平均延迟

最近告警:
  - 彩色级别标识
  - 时间和详细信息

性能趋势:
  - ASCII 柱状图
  - 最近10次检查的分数
```

### 6. 快速启动向导

**文件**: `vpn-tools/quick_start_monitoring.sh`

**核心功能**:
- ✅ 一键初始化整个监控系统
- ✅ 自动检查依赖和服务状态
- ✅ 交互式引导安装
- ✅ 显示详细的下一步操作

**启动流程**:
1. 检查系统依赖（curl、systemctl、cron）
2. 验证 Clash 服务状态
3. 初始化目录结构
4. 创建告警配置
5. 运行初始健康检查

7. 显示使用指南

## 🔧 使用指南

### 快速开始（3分钟）

```bash
cd /path/to/clash-for-linux-install/vpn-tools

# 方式1: 一键启动（推荐）
./quick_start_monitoring.sh

# 方式2: 手动安装
./setup_monitoring_cron.sh --setup
./setup_monitoring_cron.sh --install
./network_dashboard.sh
```

### 日常使用

**早上启动**:
```bash
# 查看仪表盘
./network_dashboard.sh

# 如果健康分数低，运行修复
./network_health_monitor.sh
```

**工作前准备**:
```bash
# AI 工作
./optimize_ai.sh

# 开发工作
# (自动通过规则优化)

# 观看视频
./select_youtube_node.sh

# 开会
./fix_zoom_connectivity.sh
```

**遇到问题**:
```bash
# 1. 快速诊断
./quick_vpn_check.sh

# 2. 全面检查
./network_connectivity_test.sh full

# 3. 自动修复
./network_health_monitor.sh

# 4. 运行时修复
bash ../script/runtime_guard.sh --auto-fix
```

### 定期维护

**每周**:
```bash
# 性能趋势分析
./network_dashboard.sh

# 规则优化
./intelligent_rule_optimizer.sh --analyze
./intelligent_rule_optimizer.sh --optimize
```

**每月**:
```bash
# 备份配置
cp -r ~/.local/share/clash/resources/ ~/clash_backup_$(date +%Y%m%d)/

# 清理日志
find ~/.local/share/clash/logs/ -mtime +30 -delete

# 查看历史数据
./alert_notification.sh --history
```
